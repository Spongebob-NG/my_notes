```c
void destroy(gra* g) {
	for (int i = 0; i < g->vnum; i++) {
		arcnode* p = g->vex[i].firstarc;
		while (p) {
			arcnode* s = p;
			if (p->ivex==i) {
				p = p->ilink;
				free(s);
			}
			else {
				p = p->jlink;
			}
		}
		g->vex[i].firstarc = NULL;
	}
}
```

这样写绝对会出事，因为如果p->ivex==i的时候，已经free掉这个空间了，系统连看都不让你看一眼，以至于后来即使是遇到p=p->jlink跳过这个节点的时候也会报错。

多重邻接表不推荐destroy，非要非要destroy的话就在前面加个数组存每个边节点的地址，然后挨个删
