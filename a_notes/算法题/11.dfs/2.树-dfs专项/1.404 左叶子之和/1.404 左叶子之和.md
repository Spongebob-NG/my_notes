```c++
class Solution {
public:
    int sum = 0;
    void dfs(TreeNode* root, bool flag) {
        if (!root)return;
        if (!root->left && !root->right&&flag==1)sum += root->val;
        dfs(root->left, 1);
        dfs(root->right, 0);
    }
    int sumOfLeftLeaves(TreeNode* root) {
        dfs(root, 0);
        return sum;
    }
};
```

要计算左叶子之和，首先要判断这个节点是否为叶子（这个很好判断），然后要知道这个叶子是不是左叶子。

然而，左叶子自己本身不知道自己是左叶子，要靠父亲知道，所以父亲遍历左右叶子的时候可以专门加个flag状态，如果flag是1就是左叶子，是0就是右叶子（**以后都可以参考这样的思路来判断自己的身份**）
