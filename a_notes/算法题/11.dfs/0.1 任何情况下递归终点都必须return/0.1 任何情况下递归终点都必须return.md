如下代码容易造成爆栈：

```c++
#include<iostream>
using namespace std;
int ans = 0;
int n, k;
void dfs(int m, int sum, int num) {
	if (m == k && sum == n) {
		ans++;
		return;
	}
	for (int i = num; sum + (k - m) * i >= n && i >= 1; i--) {
		//if (sum + i + (k - m - 1) * 1 > n)continue;
		dfs(m + 1, sum + i, i);
	}
}
int main() {
	cin >> n >> k;
	dfs(0, 0, n);
	cout << ans << endl;
}
```

理由：判断条件是if (m == k && sum == n) ，如果不满足这个条件的话，就算m大于了k，也还是会继续一直向下遍历！！**所以在遍历到终点格子的时候，其余任何条件都应该放在if(m==k)之下，最后无论如何都会return** 否则会爆栈
