理解二分法最好的就是红蓝染色法 **红代表一定不满足 蓝代表一定满足** 具体什么代表红 什么代表蓝 要看区间开合以及left right初始值

这里就拿lower_bound来举例子

左右都是闭:

```c++
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int n = nums.size();
        int left = 0, right = n-1;
        //left-1永远是红 也就是不满足条件的
        //right+1永远是蓝 也就是满足条件的
        //最终要返回right+1,刚好也是最后的left
        while (left <= right) {
            int mid = (right - left) / 2 + left;
            if (nums[mid] < target) {
                left = mid + 1;
            }
            else right = mid - 1;
        }
        return left;

    }
};
```

左闭右开:

```c++
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int n = nums.size();

        //left-1永远是红 也就是不满足条件的
        //right永远是蓝 也就是满足条件的
        //最终要返回right,刚好也是最后的left
        while (left < right) {
            int mid = (right - left) / 2 + left;
            if (nums[mid] < target) {
                left = mid + 1;
            }
            else right = mid;
        }
        return left;

    }
};
```

左右都开:

```c++
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int n = nums.size();
        int left = -1, right = n;
        //left永远是红 也就是不满足条件的
        //right永远是蓝 也就是满足条件的
        //最终要返回right
        while (left+1 < right) {
            int mid = (right - left) / 2 + left;
            if (nums[mid] < target) {
                left = mid;
            }
            else right = mid;
        }
        return right;
    }
};
```
