```c++
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int, int>count;
        int n = nums.size();
        vector<int>preSum(n + 1, 0);
        preSum[0] = 0;
        count[0] = 1;
        int ans = 0;
        for (int i = 0; i < n; i++) {
            preSum[i + 1] = preSum[i] + nums[i];
            if (count.find(preSum[i + 1] - k) != count.end())ans += count[preSum[i + 1] - k];
            count[preSum[i + 1]]++;
        }
        return ans;
    }
}; 
```

这种题型很久没做了 刷hot100的时候,第一次竟然是用unordered_set来写的 忘记了前面可能有多个子数组匹配的可能.

不过最大的问题还是 **count[preSum[i + 1]]++的时机**  必须要在逻辑结束之后才能加 因为是要看之前的历史有没有匹配的,所以当前这个点千万不能加 如果加了的话 当k=0的时候 就是匹配到自己了 然而前面匹配到的数组是空的 但是也作为正确答案+1了

总之  这种边计算逻辑边更新的  通常情况下都是在**最后一步更新自己**
