这道题最开始想到的肯定是哈希表 因为很简单 而且只要遍历一遍A的链表 然后再遍历一遍B的链表 看看哪个地方一样 直接返回就行了

但是这里还是介绍一下双指针的方法:

如果有相交点的话,在相交点之前的路程长度大概率是不一样的  在相交点之后长度是一样的.那不妨弄两个指针,跑完一条链表之后再跑对方的链表,这样的话两个指针在相交点相遇的时候 跑的路程也一样.比如说A在相交点前面路程是2,  B在相交点前面路程是3  **那么pa就是先跑2再跑3  pb就是先跑3再跑2**   然后相遇了就直接返回这个节点就行了.  如果说**不相交的话,同样适用**,因为都是跑完两条完整的链表 最终pa和pb都会变成nullptr

```c++
  using node = ListNode*;
  class Solution {
  public:
      ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
          if (headA == nullptr || headB == nullptr)return nullptr;
          node pa = headA;
          node pb = headB;
          while (pa != pb) {
              pa = (pa == nullptr) ? headB : pa->next;
              pb = (pb == nullptr) ? headA : pb->next;
          }
          return pa;
      }
  };
```
