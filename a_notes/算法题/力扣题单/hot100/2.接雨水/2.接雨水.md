这道题单调栈的解法已经滚瓜烂熟了  所以着重讲一下**动态规划**和**双指针**的解法

先说明一个点就是 每个下标i能存储的雨水量 等于i左边最大高度与i右边最大高度 中的最小值 再减去当前height[i]

最开始是用到动态规划 弄两个数组 一个存每个下标左边最大值 一个存每个下标右边最大值 但是面试官有可能会问我们空间复杂度为O(1)的解法  所以这个时候就衍生出了双指针

其实双指针思路很简单 就是比较leftMax和rightMax的大小  如果左边小的话 就让left往右走 如果右边小的话 就让right往左走  这样来回交替(if条件里面的等号放哪个分支都是一样的 如if(leftMax>=rightMax) )  但是最开始卡在这个双指针的解法很久  是因为力扣官方的题解代码还是太简略了  才走了弯路  它比较的是left和right 而不是直接的leftMax和rightMax

以下附上源代码

```c++
class Solution {
public:
    int trap(vector<int>& height) {
        int ans = 0;
        int n = height.size();
        int left = 0, right = n - 1;
        int leftMax = 0, rightMax = 0;
        while (left <= right) {
            if (leftMax <= rightMax) {
                leftMax = max(leftMax, height[left]);
                ans += leftMax - height[left];
                left++;
            }
            else {
                rightMax = max(rightMax, height[right]);
                ans += rightMax - height[right];
                right--;
            }
        }
        return ans;
    }
};
```
