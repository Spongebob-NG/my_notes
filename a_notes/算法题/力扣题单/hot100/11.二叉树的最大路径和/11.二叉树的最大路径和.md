这道题最开始卡住的点就是 不一定经过根节点 感觉比较随意 能在树中随便找几个连起来的节点 算最大值 所以不好找 感觉没头绪

但是要记住 **二叉树**的题 首先往**递归**方向去想肯定没毛病 所以就写一个函数 每次都返回这个节点对父节点做出的**贡献** 然后在贡献的同时 自己本身也作为某个树的根节点 算一下经过这个节点的最大值就好 所以思路就很明确了:如果是计算贡献的话 只能计算一边的子树 看哪边值大就选哪边(**要与0比较一下** 因为可能两棵子树都不选 不然的话有负数还不如不选) 然后贡献算完之后就更新一下ans  这个时候就可以左右子树都算进来了 当然了也是要跟0比较一下

```c++
using node = TreeNode*;
class Solution {
public:
    int ans = INT_MIN;
    int helper(TreeNode* root) {
        if (!root)return 0;
        int gain_left = helper(root->left);
        int gain_right = helper(root->right);
        int contribution = root->val + max(0, max(gain_left, gain_right));
        int curr_max = root->val + max(0, gain_left) + max(0, gain_right);
        ans = max(ans, curr_max);
        return contribution;
    };
    int maxPathSum(TreeNode* root) {
        helper(root);
        return ans;
    }
};
```
