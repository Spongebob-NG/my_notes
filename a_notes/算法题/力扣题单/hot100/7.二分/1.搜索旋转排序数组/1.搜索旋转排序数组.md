这道题 第一个方法的思路就是 先算出循环数组基于原数组的偏移量 之后二分法的时候 left和right还是设为-1和n(开区间方法) 算出来mid之后再根据偏移量pivot算出当前的循环数组的值  总之就是**先假装数组没有旋转**  然后再**根据mid映射到旋转后的数组**

不过这里找循环数组中的最小值时 也有个小巧思 就是也用到二分法 而且这个地方刚好也印证了红蓝染色法对于二分算法的普适性 并且在这里刚好总结了一个很好的经验：但凡遇到**二分算法** 其实**left和right都搞成开区间**就好了 因为这样的话 假如**左边是红** **右边是蓝** 那么**left刚好就是满足条件的那个 right刚好就是不满足条件的那个** 最后循环条件**left+1<right**刚好就是代表着**还有元素没有处理完**

```c++
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int pivot = -1;
        int n = nums.size();
        int left = -1, right = n - 1;
        while (left + 1 < right) {
            int mid = (right - left) / 2 + left;
            if (nums[mid] <= nums[n - 1])right = mid;
            else left = mid;
        }
        pivot = right;
        left = -1, right = n;
        while (left+1 < right) {
            int mid = (right - left) / 2 + left;
            int real_mid = (mid + pivot) % n;
            if (nums[real_mid] == target)return real_mid;
            else if (nums[real_mid] < target)left = mid;
            else right = mid;
        }
        return -1;
    }
};
```

第二个方法就是只能针对这道题目了 用**一次二分法**就能找到答案 思路就是 **每次二分**了之后 **都找有序的一边** 然后判断target是不是在里面 是与不是都能更新边界  然后继续找下一次有序的一边

ps： 这个一定**不能用红蓝染色法**来想！！因为这个不是单调数组！只有单调数组 也就是第一种方法 能用红蓝染色法！！

```c++
class Solution {
public:
    int search(vector<int>& nums, int target) {
        int n = nums.size();
        int left = 0, right = n - 1;
        while (left <= right) {
            int mid = (right - left) / 2 + left;
            if (nums[mid] == target)return mid;
            if (nums[left] <= nums[mid]) {
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1;
                }
                else left = mid + 1;
            }
            else {
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1;
                }
                else right = mid - 1;
            }
        }
        return -1;
    }
};
```
