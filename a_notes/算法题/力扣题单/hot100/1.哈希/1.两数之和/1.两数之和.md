```c++
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int>count;
        for (int i = 0; i < nums.size(); i++) {
            auto it = count.find(target - nums[i]);
            if (it!= count.end()) {
                return { it->second,i };
            }
            count[nums[i]] = i;
        }
        return {};
    }
};
```

这道题 一开始想到用哈希表 但是比较笨拙 用了两个  一个用来看数组里面有没有这个数 一个用来记录数组的下标.后来才发现可以只用一个哈希表同时解决这两种事

再一个尤其需要注意的点是 这种题 把当前的数据添加到哈希表中的时机,是**在前面所有逻辑处理完之后**.如果当前的数据在逻辑处理之前就添加到哈希表里面的话,就会污染之前的哈希表
