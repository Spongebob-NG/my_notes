这道题说实话卡了很久 后面形成了一个固定的思路 就是选子集的话 子集里面的元素只能**按照下标增大的方向排列** 这样的话才不会出现重复的子集 所以只能增加一个start 之后选择的下标必须满足大于start并且没有被选择过

```c++
class Solution {
public:
    vector<vector<int>>ans;
    vector<int>temp;
    void helper(vector<int>& nums, int start, vector<bool>& flag) {
        ans.push_back(temp);
        if (start == nums.size())return;
        for (int i = start; i < nums.size(); i++) {
            if (flag[i])continue;
            flag[i] = true;
            temp.push_back(nums[i]);
            helper(nums, i+1, flag);
            temp.pop_back();
            flag[i] = false;
        }
    }
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<bool>flag(nums.size(), false);
        helper(nums, 0, flag);
        return ans;
    }
};
```

不过这道题其实这样做的话 **空间复杂度会有点高** 因为仔细一想 其实bool数组可以完全不要 因为每次都是在start+1的地方开始选 永远不可能回头选之前选过的下标所对应的数字 所以优化之后如下:

```c++
class Solution {
public:
    vector<vector<int>>ans;
    vector<int>temp;
    void helper(vector<int>& nums, int start) {
        ans.push_back(temp);
        for (int i = start; i < nums.size(); i++) {
            temp.push_back(nums[i]);
            helper(nums, i + 1);
            temp.pop_back();
        }
    }
    vector<vector<int>> subsets(vector<int>& nums) {
        helper(nums,0);
        return ans;
    }
};
```
