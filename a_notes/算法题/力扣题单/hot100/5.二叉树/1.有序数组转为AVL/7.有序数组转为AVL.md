这道题一开始就是用最正统的二叉排序树  然后弄了个函数专门来获取每棵树的高度  但是毕竟不是树中自带的高度 还要函数自己算 所以效率肯定是不敢恭维 而且中间还涉及到翻转的操作

所以这道题更好的办法其实是用分治 刚好也算是练习了一下分治算法

```c++
using node = TreeNode*;
class Solution {
public:
    node helper(int left,int right,vector<int>&nums) {
        if (left > right)return nullptr;
        int mid = (left + right) / 2;
        node root = new TreeNode(nums[mid]);
        root->left = helper(left, mid - 1,nums);
        root->right = helper(mid + 1, right, nums);
        return root;
    }
    TreeNode* sortedArrayToBST(vector<int>& nums) {
        node root = helper(0, nums.size() - 1, nums);
        return root;
        
    }
};
```
