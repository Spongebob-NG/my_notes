这道题绕了很久 总结一下代码就是 如果**当前是空节点 肯定要返回nullptr** 这个毫无疑问. 之后呢 **如果这个是p或者q本身 那也直接返回这个节点 告诉上面的节点说找到p或者q了** 之后的逻辑就是 如果**既不是p也不是q 那就在左右子树里面都找一下p或者q** 如果左右子树**都不是空的话 那就直接返回这个节点作为最近公共祖先**. 如果左右子树**有一边是空**的话 那就**先找左子树** 看左子树是不是空的 如果**左子树不是空的 那就直接返回左子树的结果**(因为左子树这个时候也是接收了下面的节点递归的结果 所以**left送上来的其实就是递归找到的结果**) 如果左子树找不到的话 那确定就是在这个节点的**右子树**里面了

```c++
using node = TreeNode*;
class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (!root || root == p || root == q)return root;
        node left = lowestCommonAncestor(root->left, p, q);
        node right = lowestCommonAncestor(root->right, p, q);
        if (left && right)return root;
        if (left)return left;
        return right;
    }
};
```
