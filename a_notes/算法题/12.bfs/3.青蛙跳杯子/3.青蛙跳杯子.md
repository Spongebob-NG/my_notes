这道题一开始还是想不出啥思路出来，经过提示之后，发现这种求最短路径/最小步数的，基本都可以用BFS来求解，而且每一层都是放在队列里面，遍历完一层之后再遍历下一层 

```c++
#include <iostream>
#include<unordered_map>
#include<queue>
using namespace std;
string src, dest;
int dx[6] = { -3,-2,-1,1,2,3 };
struct node {
	string s;
	int xi;
	int step;
};
int ans = 0;
void bfs() {
	int xi = -1;
	for (int i = 0; i < src.length(); i++) {
		if (src[i] == '*') {
			xi = i;
			break;
		}
	}
	queue<node>q;
	unordered_map<string, int>flag;
	q.push({src,xi});
	flag[src] = 1;
	while (!q.empty()) {
		int index = q.front().xi;
		string s = q.front().s;
		int step = q.front().step;
		q.pop();
		for (int i = 0; i < 6; i++) {
			string temp = s;
			int xii = index + dx[i];
			if (xii < 0 || xii >=src.size())continue;
			char a = temp[xii];
			temp[xii] = temp[index];
			temp[index] = a;
			if (flag[temp] != 0)continue;
			if (temp == dest) {
				cout << step + 1 << endl;
				exit(0);
			}
			q.push({ temp,xii,step+1 });
			flag[temp]++;
		}
		ans++;
	}
}
int main()
{
	cin >> src >> dest;
	if (src == dest) {
		cout << 0 << endl;
		exit(0);
	}
	bfs();


	return 0;
}
```



--------



关于怎么看出来这道题使用BFS的：

### ## 1. 核心判定：为什么这道题必须是 BFS？

在算法竞赛中，判定 BFS 的黄金准则只有两条：

1. **关键词：求“最少”、“最短”、“最快”**。
   - DFS 的特长是“有没有路”、“有多少条路”。
   - BFS 的特长是“**哪条路最近**”。
2. **权值相等（每一步的代价都一样）**。
   - 在这道题里，跳 1 格、2 格、3 格都算作“一步”。只要每一步的代价都是 1，BFS 就像水波纹一样，第一层是所有 1 步能到的，第二层是所有 2 步能到的……它**第一次**碰到目标时，绝对就是最少步数。

> **形象比喻**：
>
> - **DFS** 像是一个**疯子**，不撞南墙不回头，它可能绕了一大圈才找到出口，你还得回过头来比谁绕得圈子小。
> - **BFS** 像是一个**情报网**，从起点向四周同时扩散。第一波情报员带回来的终点信息，绝对是路程最短的。

 BFS 必胜三板斧

当你决定用 BFS 时，代码结构永远是这三步：

1. **队列 (Queue)**：存储待探索的“平行宇宙”。
   - *注意*：一定要把**步数**跟状态绑定。要么存 `struct {string s, int step}`，要么用 `map` 存。
2. **判重 (Visited)**：这是防止程序跑死的唯一手段。
   - *原理*：**如果一个样子已经出现过了，再从它出发绝对不会比第一次遇到它时步数更短。**
3. **方向数组/逻辑 (Transitions)**：
   - 在迷宫里是 `dx, dy`。
   - 在这里是 `dx = {-3, -2, -1, 1, 2, 3}` 产生的 `swap` 逻辑。

------

### ## 4. 蓝桥杯省一选手的避坑总结

- **越界检查是头等大事**：在 `swap` 之前，必须检查 `xii` 是否在 `[0, s.length() - 1]` 之间。
- **不要混用全局变量**：BFS 是多分支并行的，每一个分支必须拥有自己的 `string` 副本和 `index`。
- **效率选择**：
  - 如果状态是数字，用数组查重最快。
  - 如果状态是字符串，`unordered_map` (哈希表) 比 `map` (红黑树) 快得多。
- **提前退出**：一旦在入队前发现 `temp == dest`，直接 `cout << step + 1` 然后 `exit(0)`，这是最省时间的写法。
