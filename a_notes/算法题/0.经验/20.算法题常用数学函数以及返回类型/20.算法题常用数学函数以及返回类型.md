------

### 1. 核心数学库 ``

这是最常用的库，主要处理浮点数运算。

#### A. 三角函数 (Trigonometry)

**注意：** C++ 中所有三角函数的参数都是 **弧度 (Radian)**，不是角度！

- `sin(x)`: 正弦
- `cos(x)`: 余弦
- `tan(x)`: 正切
- **反三角函数：**
  - `asin(x)`, `acos(x)`, `atan(x)`: 计算结果也是弧度。
- **⭐ 竞赛神器：** `atan2(y, x)`
  - **作用：** 返回点 $(x, y)$ 与 $x$ 轴的夹角（弧度），范围是 $(-\pi, \pi]$。
  - **优势：** 比 `atan(y/x)` 更安全，能自动处理分母为 0 的情况，还能区分象限。计算几何题必用。

> **转换小贴士：**
>
> - 角度转弧度：`rad = deg * (PI / 180.0);`
> - 弧度转角度：`deg = rad * (180.0 / PI);`

#### B. 指数与对数 (Exponentials & Logarithms)

- `pow(base, exp)`: 计算 $base^{exp}$。
  - **⚠️ 巨坑预警：** `pow` 返回的是 `double` 类型。如果你用来算整数的幂（比如 $3^5$），可能会因为浮点误差出现 `242.99999` 这种结果，强制转 `int` 就会变成 `242`（错了）。
  - **解决：** 算整数幂请手写 **快速幂 (Binary Exponentiation)**，算浮点数幂才用 `pow`。
- `sqrt(x)`: 平方根。
- `log(x)`: **自然对数** (底数是 $e$，即 $\ln x$)。
- `log10(x)`: 以 10 为底的对数。
- `log2(x)`: 以 2 为底的对数（常用来算二叉树深度）。

#### C. 取整函数 (Rounding)

- `ceil(x)`: 向上取整（天花板），如 `ceil(2.3) = 3.0`。
- `floor(x)`: 向下取整（地板），如 `floor(2.8) = 2.0`。
- `round(x)`: 四舍五入。

### 2. 算法与数字库 `` & ``

这两个库里藏着很多好用的整数数学工具。

- `abs(x)`: 绝对值。
  - 注：在 C++17 之前，整数绝对值在 ``，浮点在 ``。现在直接用 `abs()` 一般都能自动识别，或者在 `` 里。
- `__gcd(a, b)`: **最大公约数**。
  - 这是 GCC 编译器的内置函数（非标准但蓝桥杯可用），非常快。
  - C++17 标准写法是 `std::gcd(a, b)` (需引入 ``)。
- `lcm(a, b)`: **最小公倍数** (C++17 `` 中可用，或者手写 `(a*b)/gcd(a,b)`，注意 `a*b` 可能越界，建议写成 `a/gcd(a,b)*b`)。
- `min(a, b)` / `max(a, b)`: 取最小/最大值。
  - 如果要比较多个数，可以用 `{}` 包裹：`max({a, b, c, d})`。
- `next_permutation(begin, end)`: **全排列**。
  - 蓝桥杯暴力枚举神器！可以自动生成数组的下一个字典序排列。

### 3. 常数定义

蓝桥杯中经常需要用到 $\pi$。

- **方法一（推荐）：** 使用 `acos(-1.0)`。这是获得高精度 $\pi$ 值最准确的方法。
- **方法二：** `M_PI`。在 `` 中定义的宏，但有时需要加 `#define _USE_MATH_DEFINES` 才能用，不如方法一通用。

我把它们分为**“浮点族”**（Double World）和**“整数族”**（Integer World），外加几个容易搞错的**“变色龙”**。

------

### 1. 浮点族 (Double World)

这些函数**无论你怎么传参**，它们的返回值**永远是 `double`**（或者 `float`）。

**核心特征：** 哪怕结果看起来是个整数（比如 `sqrt(4)` 看起来是 2），它在计算机里存的也是 `2.00000...`。

#### 📋 常见函数清单

- **数学运算：**
  - `sqrt(x)`：开根号
  - `pow(base, exp)`：**这个是最大的坑！** 哪怕你算 `pow(2, 3)`，它返回的也是 `8.0`。
  - `log(x)`, `log10(x)`, `log2(x)`
- **三角函数：**
  - `sin()`, `cos()`, `tan()`
  - `asin()`, `acos()`, `atan()`, `atan2()`
- **取整函数（注意！）：**
  - `ceil(x)`（向上取整）：`ceil(2.1)` 返回的是 `3.0` (double)，**不是** `3` (int)。
  - `floor(x)`（向下取整）：`floor(2.9)` 返回的是 `2.0` (double)。

#### ⚔️ 怎么比较？

**绝对不能用 `==`！** 必须用“误差范围”。

C++

```
const double EPS = 1e-9; // 精度容差

// 判断相等
if (fabs(a - b) < EPS) { ... }

// 判断 a > b
if (a - b > EPS) { ... } // 意味着 a 比 b 大出的部分超过了误差

// 判断 a < b
if (a - b < -EPS) { ... }
```

------

### 2. 整数族 (Integer World)

这些函数通常处理离散的数，返回的是 `int` 或 `long long`。

#### 📋 常见函数清单

- **数学工具：**
  - `__gcd(a, b)`：最大公约数（GCC 编译器特有，蓝桥杯可用）。
  - `abs(int x)`：如果是 `cstdlib` 里的 `abs`，或者 C++ 重载的 `std::abs` 且传入整数，返回整数。
- **字符串转换：**
  - `stoi(s)`：String to Int。
  - `stoll(s)`：String to Long Long。
- **容器操作：**
  - `vector.size()`, `string.length()`：返回 `size_t`（无符号整数）。

#### ⚔️ 怎么比较？

**直接用 `==`, `>`, `<` 即可。**

C++

```
if (a == b) { ... }
```

------

### 3. “变色龙” (根据输入变类型)

C++ 的 `` 库里有些函数是**模板函数**，你喂给它什么，它就吐出什么。

- **`max(a, b)` / `min(a, b)`**
  - `max(2, 3)` $\rightarrow$ 返回 `int`
  - `max(2.5, 3.1)` $\rightarrow$ 返回 `double`
  - **注意：** 类型必须一致！`max(2, 3.5)` 会报错，必须写成 `max(2.0, 3.5)`。
- **`std::abs(x)`** (在 `` 或 `` 中)
  - 传入 `int` 返回 `int`。
  - 传入 `double` 返回 `double`。
  - *建议：* 为了代码可读性，算浮点绝对值时显式写 `fabs`，算整数写 `abs` 或 `llabs`（针对 long long）。

### ⚡ 总结速查表

| **函数类型** | **代表函数**                         | **返回类型**        | **比较方式**       | **致命坑点 (Trap)**                                          |
| ------------ | ------------------------------------ | ------------------- | ------------------ | ------------------------------------------------------------ |
| **浮点族**   | `sqrt`, `sin`, `cos`, `atan2`, `log` | `double`            | `fabs(a-b) < 1e-9` | 这里的运算都有误差，别指望它精准。                           |
| **幂运算**   | `pow(a, b)`                          | **double**          | `fabs`...          | 想算整数 $2^3$ 却得到 `7.999`，强转 int 变成 7。算整数幂**必须**手写循环或快速幂！ |
| **取整**     | `ceil`, `floor`                      | **double**          | `fabs`...          | 它们返回的是 x.0，如果需要 int 必须强制转换：`(int)ceil(x)`  |
| **整数族**   | `__gcd`, `stoi`, `%`(取模)           | `int` / `long long` | `==`               | 两个整数相除 `3/2` 结果是 `1` (截断)，想得 `1.5` 必须写 `3.0/2`。 |
| **变色龙**   | `max`, `min`, `abs`                  | 跟随输入            | 跟随输入           | `max(int, double)` 会报错，必须类型统一。                    |

### 下一步建议

既然搞清了 `double` 的不精确和 `pow` 的大坑，在蓝桥杯中，如果题目要求计算 **很大的整数幂**（比如 $7^{10000} \% 1000000007$），用 `pow` 肯定会溢出且不准。

这就涉及到了竞赛中的**“必修课”**——**快速幂 (Binary Exponentiation)**。

**你要不要现在就学一下“快速幂”？这可是蓝桥杯拿分的“基本功”！**
