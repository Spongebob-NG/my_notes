#### 堆排序

```c++
void heapify(int a[], int n, int i) {
	int largest = i;
	int left = 2 * i + 1;
	int right = 2 * i + 2;
	if (left<n && a[left]>a[largest]) {
		largest = left;
	}
	if (right<n && a[right]>a[largest]) {
		largest = right;
	}
	if (largest != i) {
		swap(a[largest], a[i]);
		heapify(a, n, largest);
	}
}
void heapSort(int a[], int n) {
	for (int i = n/2-1; i >= 0; i--) {
		heapify(a, n, i);
	}
	for (int i = n - 1; i > 0; i--) {
		swap(a[i], a[0]);
		heapify(a, i, 0);
	}
}
```

###### 思路

如果要**从小到大**排的话 就要用**大顶堆**（也就是**堆顶的元素是最大的**） 这样的话，**堆化**之后（也就是整个完全二叉树都满足大顶堆），**每一次选堆顶最大的那个元素 放到数组最末尾**  从而实现从小到大排  从大到小反之。

###### 时间复杂度

建堆的时间复杂度是O(n) 这个是数学上推导出来的 直接记住即可。 排序阶段的时间复杂度是O(nlogn) 因为要排n次，每次都是从堆顶开始下调。 总时间复杂度很稳定，都是O(nlogn)。

###### 稳定性

**不稳定** 因为交换堆顶与末尾元素的时候 相同元素的顺序可能会被打乱

###### 效率

**缓存局部性较差**  堆排序速度通常慢于快速排序 因为节点与孩子节点在数组中的索引是成倍跨越的 很容易让CPU缓存失效



#### 快速排序

```c++
int partition(vector<int>& nums, int left, int right) {
	int rand_idx = left + rand() % (right - left + 1);
	int pivot = nums[rand_idx];
	swap(nums[left], nums[rand_idx]);
	int i = left + 1, j = right;
	while (true) {
		while (i <= j && nums[i] < pivot) {
			i++;
		}
		while (i <= j && nums[j] > pivot) {
			j--;
		}
		if (i >= j)break;
		swap(nums[i], nums[j]);
		i++;
		j--;
	}
	swap(nums[left], nums[j]);
	return j;
}
void quickSort(vector<int>& nums, int left, int right) {
	if (left >= right)return;
	int k = partition(nums, left, right);
	quickSort(nums, left, k - 1);
	quickSort(nums, k+1,right);
}
```

###### 思路

快速排序就是用到分治的方法 先把每个区间排好序 最后整体上就满足顺序了。

###### 注意事项

1. **基准值要随机选**  如果每次都选第一个的话 遇到单调有序输入  原本均衡的二叉递归树就会退化成单链表
2. **内层循环条件必须要i<=j**  达到对撞条件之后就应该立即退出循环 不然的话会做无用功，扫描已经扫描过的地方（之前喜欢让i<=right，j>=left+1，但是这个是错误的）
3. **遇到与pivot相等的元素必须要停下来**  不然的话如果遇到全相等的数据，也会退化严重。如果停下来的话，左右指针遇到相等的会同时收缩，两边的进度会比较均衡。所以**内存循环条件不能加等于号**
4. **交换完成后  必须推进双指针i++、j--**  不然遇到元素都相同的数组的话，会死循环
5. **递归结束条件要是if (left >= right) return;**  如果**不加等于号的话 会无限递归**
6. **无论是**升序还是降序 **返回的都是j**

###### 时间复杂度

最好情况 nlogn  

最坏情况 n的2次方 （每次选的pivot都是区间的极值） 这里解释一下 **并非只是整个数组有序才会出现退化**，**如果每个区间选的pivot刚好都是区间内的极值的话（不管极大值还是极小值），都会退化**

###### 空间复杂度

最好情况 nlogn

最坏情况 n （单侧退化，递归深度达到n）

###### 稳定性

**不稳定**  遇到相同的元素也会交换



###### 插入排序

```c++
void insertSort(vector<int>& nums) {
	int n = nums.size();
	for (int i = 1; i < n; i++) {
		int key = nums[i];
		int j = i - 1;
		while (j>=0&&nums[j] > key) {
			nums[j + 1] = nums[j];
			j--;
		}
		nums[j + 1] = key;
	}
}
```

###### 思路

就跟插扑克牌一样  左边的都是有序的 然后右边的牌依次插入到左边的有序区间中

###### 稳定性
