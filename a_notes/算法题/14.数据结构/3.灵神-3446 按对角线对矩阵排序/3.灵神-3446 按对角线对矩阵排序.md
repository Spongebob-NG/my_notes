```c++
class Solution {
public:
    vector<vector<int>> sortMatrix(vector<vector<int>>& grid) {
        unordered_map<int, vector<int>>diag;
        int n = grid.size(); int m = grid[0].size();
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                diag[j - i].push_back(grid[i][j]);
            }
        }
        for (auto& [k, m] : diag) {
            if (k <= 0)sort(m.begin(), m.end(), greater<int>());
            else sort(m.begin(), m.end());
        }
        unordered_map<int, int>cnt;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                grid[i][j] = diag[j - i][cnt[j - i]];
                cnt[j - i]++;
            }
        }
        return grid;
    }
};
```

这题有很多个小点值得回味：

1.矩阵的同一对角线 行和列相减的结果是一样的，可以利用这一点来让哈希表存储

2.哈希表的值可以是vector数组，并且可以按照题意对其进行排序

3.遍历哈希表的元素可以 **for (auto& [k, m] : diag)** 这是新特性

4.可以用cnt记录已经排过的下标
