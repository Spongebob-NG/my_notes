```c++
class Solution {
public:
    vector<int> findKDistantIndices(vector<int>& nums, int key, int k) {
        int last = -k - 1;
        for (int i = k - 1; i >= 0; i--) {
            if (nums[i] == key) {
                last = i;
                break;
            }
        }
        int n = nums.size();
        vector<int>ans;
        for (int i = 0; i < nums.size(); i++) {
            if (i + k < n && nums[i + k] == key)last = i + k;
            if (last >= i - k)ans.push_back(i);
        }
        return ans;
    }
};
```

灵神：

思路就是看大小为2*k+1的窗口里面有没有满足key的值，如果有的话就加入答案中

这个设计比较巧妙，一开始先把k初始化成一个比i-k小的数，后面如果有**nums[i+k]等于key的话，就让last等于最后的那个key的下标**。同时再判断对于每个i，last是不是大于等于i-k（**如果last在i的右边的话，理所当然加入i，因为last最大值就是i+k，这里确定了右边界。**）
