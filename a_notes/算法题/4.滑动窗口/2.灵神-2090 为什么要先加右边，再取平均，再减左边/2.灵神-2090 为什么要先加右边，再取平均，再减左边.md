```c++
class Solution {
public:
    vector<int> getAverages(vector<int>& nums, int k) {
        int left = 0,mid=0,right=mid+k;
        long long sum = 0;
        int ave = 0;
        vector<int>ans(nums.size(),-1);
        while (right < nums.size()) {
            if (mid < k) {
                sum += nums[mid];
                sum += nums[right++];
            }
            else {
                sum += nums[right++];
                ave = sum / (2 * k + 1);
                ans[mid] = ave;
                sum -= nums[left++];
            }
            mid++;
        }
        return ans;
    }
};
```

关于这种定长滑动窗口题，都能用三个步骤来--**入->更新->出**

做了两个题，老是摔在一个地方，就是当满足了定长的时候，会忘记加right的值，所以满足定长之后不如先加了right的值，再判断average或者其他（更新），再出掉left的值
