```c++
class Solution {
public:
    bool containsNearbyAlmostDuplicate(vector<int>& nums, int indexDiff, int valueDiff) {
        multiset<long long>a;
        int l = 0, r = 0;
        while (r < nums.size()) {
            auto x = a.lower_bound(nums[r] - valueDiff);
            if (x != a.end() && *x <= nums[r] + valueDiff)return true;
            a.insert(nums[r++]);
            if (r - l > indexDiff)a.erase(a.find(nums[l++]));
        }
        return false;
    }
};
```

这一题真的耗了很久很久，逻辑先不说，里面要用到一个新容器，**multiset**，它相当于是自动排序的数组，如果要从滑动窗口左边出元素的话，得用a.erase(a.find(nums[l++]))，不然a.erase(num)是会直接删除掉所有的num的

还有一点，就是跟Claude说的一样，其实可以不用像之前那样if-else语句，因为里面干的大部分事情都相同，像这样直接清爽多了，而且也满足灵神给的 加入->判断->删除 的操作（只不过这一题不能先加入了，因为i!=j，得按照题目具体来弄）

总之，题型能模板化，但过于模板化反而会局限思维
