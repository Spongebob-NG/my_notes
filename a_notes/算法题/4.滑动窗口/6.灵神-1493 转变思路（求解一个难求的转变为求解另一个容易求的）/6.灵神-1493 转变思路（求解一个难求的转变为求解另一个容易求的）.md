```c++
class Solution {
public:
    int longestSubarray(vector<int>& nums) {
        int cnt0 = 0;
        int ans = INT_MIN;
        int l = 0, r = 0;
        while (r < nums.size()) {
            cnt0 += 1 - nums[r];
            while (cnt0 > 1) {
                cnt0 -= 1 - nums[l++];
            }
            ans = max(ans, r - l);
            r++; 
        }
        return ans;
    }
};
```

这道题用的还是转变思路  既然连续的1不好求，以及只能有一个0，那么就求只包含一个0的最长子数组（数组长度为r-l而不是r-l+1，因为除去了0）
