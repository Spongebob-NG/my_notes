```c++
class Solution {
public:
    int minimumSumSubarray(vector<int>& nums, int l, int r) {
        int ans = INT_MAX;
        int n = nums.size();
        vector<int>presum(n + 1);
        multiset<int>s_set;
        partial_sum(nums.begin(), nums.end(), presum.begin() + 1);
        //s[j]-s[i]>0
        //   l<=j-i<=r
        //     j-r<=i<=j-l
        for (int j = l; j <= n; j++) {
            s_set.insert(presum[j - l]);
            auto it = s_set.lower_bound(presum[j]);
            if (it != s_set.begin())ans = min(ans, presum[j] - *(--it));
            if (j >= r) {
                s_set.erase(s_set.find(presum[j - r]));
            }
        }
        return ans == INT_MAX ? -1 : ans;
    }
};
```

这种***双变量***的问题，又是**枚举右，维护左**，同时写出对应的关系式。

在这道题可以发现，用multiset的话 能用lower_bound直接找到s[j]左边最大且小于s[j]的子数组 详情见代码（注意减一，因为要找的是最后一个小于s[j]的数）

在这道题中发现了一个需要以后一直注意的事项：**前缀和的下标i表示的是统计前i个数据的和**，因此，伪代码中l<=j-i<=r是正确的，因为这里的j和i不代表nums的下标了，而是前缀和的下标，相减之后代表的就是i和j之间的元素个数  这个地方困扰了好一会儿
