------

### ## 宏观概览：`string` 的三大能力维度

你可以把 `string` 想象成一个**“带自动扩容功能、自带搜索引擎、且能随时变身的动态字符数组”**。

1. **修改与拼接**：不仅能加，还能插，还能割。
2. **搜索与替换**：像 Word 里的“查找替换”一样方便。
3. **类型转换**：在“数字”与“字符串”之间无缝切换。

------

### ## 一、 搜索与位置（定位神器）

当你需要在一个状态里找某个特定字符（比如卡片换位里的空位）时，这些函数是首选。

| **函数**                 | **功能**                                            | **备注**                     |
| ------------------------ | --------------------------------------------------- | ---------------------------- |
| `s.find(str)`            | 查找 `str` 第一次出现的位置                         | 找不到返回 `string::npos`    |
| `s.rfind(str)`           | 查找 `str` **最后一次**出现的位置                   | “r” 代表 reverse（反向查找） |
| `s.find_first_of("abc")` | 查找字符 'a' 或 'b' 或 'c' 任意一个第一次出现的位置 | 常用于找分隔符               |

> **💡 蓝桥杯考点**：`find` 的返回值是 `size_t`，判断是否找到要写成 `if (s.find(' ') != string::npos)`。`npos` 本质上是一个极大的数，代表“不存在”。

------

### ## 二、 修改与提取（手术刀）

这是你最常用来生成“新状态”的工具。

- **`s.substr(pos, len)`**：提取子串。
  - 示例：`string s = "Hello"; s.substr(1, 2);` 得到 `"el"`。
  - **注意**：第二个参数是**长度**，不是结束下标。
- **`s.erase(pos, len)`**：删除一段。
  - 示例：`s.erase(1, 1);` 删掉下标为 1 的字符。
- **`s.insert(pos, str)`**：在某个位置插入。
- **`s.replace(pos, len, str)`**：把某一段换成别的。
- **`s.pop_back()`**：删掉最后一个字符（C++11 常用，不用再手动改长度了）。

------

### ## 三、 转换大法（蓝桥杯必考）

蓝桥杯非常喜欢考那种“给你一个数字，求它每位数字之和”或者“处理超长数字”的题。

- **数字转字符串**：`to_string(num)`
  - 不管是 `int`, `long long` 还是 `double`，统统变 `string`。
- **字符串转数字**：
  - `stoi(s)`：转 `int`。
  - `stoll(s)`：转 `long long`（数据大时必用）。
  - `stod(s)`：转 `double`。
  - **优点**：它们会自动处理负号，非常智能。

------

### ## 四、 算法“友情客串”（STL 联动）

虽然这些函数在 `` 库里，但它们跟 `string` 是死党。

- **`reverse(s.begin(), s.end())`**：字符串翻转。
  - *秒杀*：判断回文串。
- **`sort(s.begin(), s.end())`**：字符排序。
  - *秒杀*：判断两个字符串是否由相同的字符组成（字母异位词）。
- **`unique(s.begin(), s.end())`**：去重（注意要先 `sort`）。

------

### ## 五、 避坑指南：`getline` 与 `cin` 的恩怨

既然你要拿省一，这个细节必须刻在骨子里：

1. **`cin >> s;`**：读到空格、换行、制表符就停。
2. **`getline(cin, s);`**：读完整行，直到遇到换行符。

**致命陷阱**：如果你先写了 `cin >> n;`，再写 `getline(cin, s);`。

此时 `getline` 会读到 `n` 后面那个被你遗忘的**回车符**，导致读取结果为空！

- **解药**：在 `cin >> n;` 后面加一句 **`cin.ignore();`**，把那个多余的回车吃掉。

------

### ## 总结你的“新武器库”

现在你回头看“卡片换位”那题：

- **以前**：你要写双重循环找空格，要手动写 `for` 循环交换坐标。
- **现在**：
  1. `int pos = s.find(' ');`（一秒定位）
  2. `swap(s[pos], s[next_idx]);`（一秒交换）
  3. `if (vis.count(s))`（一秒判重）

这就是 C++ 这种“半底层、半高层”语言的魅力。
