##### 拼接

s=s+'a'这个要慎用，因为要实现这个操作，要先产生一个新的string对象，复制拼接完之后再销毁旧对象，时间复杂度会变高 最好用s+='a'或者说s.push_back('a')

##### 转换

**始终要记住，char是基础整形，要对它操作的时候可以就把它当做一个整型变量来看待**

比如，to_string('a')会把a转换成数字，而不是原本的字符

正解：**string s(1,'a')** ;/ **string s="";s+='a' ** 

**错误：string s = "hello" + "world";** ！  这相当于两个const char*指针相加 应该string s = string("hello") + "world";
