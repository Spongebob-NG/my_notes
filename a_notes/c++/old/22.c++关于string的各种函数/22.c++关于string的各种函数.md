# 📌 一、字符串基本操作

## ✔️ 1. 创建与初始化

```
string s1;                // 空
string s2 = "hello";      // 直接赋值
string s3(5, 'a');        // "aaaaa"
```

------

# 📌 二、字符串的核心成员函数

------

## 🔹 **1. 大小、判空**

```
s.size();        // 返回长度
s.length();      // 和 size() 完全一样
s.empty();       // 是否为空字符串
```

------

## 🔹 **2. 访问字符**

```
char c1 = s[0];        // 不检查越界
char c2 = s.at(0);     // 检查越界，越界会抛异常
s.front();             // 第一个字符（C++11）
s.back();              // 最后一个字符（C++11）
```

------

## 🔹 **3. 修改字符串**

### 🟦 append / push_back

```
s.append("abc");
s.push_back('x');
s += "abc";     // 最常用
```

### 🟦 insert（插入）

```
s.insert(2, "hello");
```

### 🟦 erase（删除）

```
s.erase(2, 3);   // 从位置2删3个字符
s.erase(2);      // 从位置2删到结尾
```

### 🟦 replace（替换）

```
s.replace(2, 3, "abc"); // 从2开始3个字符替换成 "abc"
```

------

# 📌 三、查找相关函数（超级常用）

## 🔹 find / rfind

```
s.find("abc");      // 从前向后找
s.rfind("abc");     // 从后向前找
```

返回值：

- 找到：返回下标
- 找不到：返回 `string::npos`

------

## 🔹 find_first_of / find_last_of

查找集合中任意一个字符：

```
string s = "hello world";
s.find_first_of("aeiou"); // 找到第一个元音
```

------

# 📌 四、字符串截取

## 🔹 substr（非常常用）

```
string sub = s.substr(2, 5);  // 从2开始取5个字符
string sub2 = s.substr(2);    // 取到结尾
```

------

# 📌 五、比较函数

## 🔹 compare

```
s.compare("abc");  
```

返回：

- 0：相等

- > 0：s > "abc"

- <0：s < "abc"

但一般直接用 `== < >` 就够了。

------

# 📌 六、字符串和数字互相转换

你刚学到的 `to_string` 就在这里！

------

## 🔹 **1. 数字 → 字符串**

### ✔️ **to_string()（C++11）**

```
string s = to_string(123);
```

支持所有基本数字类型：

- int
- long long
- float
- double
- 甚至 bool → "1"/"0"

------

## 🔹 **2. 字符串 → 数字**

### ✔️ stoi / stol / stoll

```
int x = stoi("123");
long y = stol("12345");
long long z = stoll("9483748374");
```

### ✔️ stof / stod

```
double d = stod("12.34");
```

------

# 📌 七、C 风格字符串互操作

## 🔹 转 C 字符串

```
s.c_str();   // const char*
```

很多旧库（如 printf）需要它。

------

# 📌 八、容量相关（了解即可）

```
s.capacity();    // 预留容量
s.reserve(100);  // 预分配容量
s.shrink_to_fit();
```

大部分时间不需要手动管。

------

# 📌 九、字符串遍历方式

## for

```
for (int i = 0; i < s.size(); i++)
    cout << s[i];
```

## range-based for（更安全）

```
for (char c : s)
    cout << c;
```

------

# 📌 十、一些冷门但非常有用的小技巧

------

## ✔️ 1. reverse（反转）

```
reverse(s.begin(), s.end());
```

------

## ✔️ 2. sort（排序）

```
sort(s.begin(), s.end());
```

------

## ✔️ 3. transform（大小写转换）

```
transform(s.begin(), s.end(), s.begin(), ::toupper);
transform(s.begin(), s.end(), s.begin(), ::tolower);
```

------
