## 一、为什么 umask 是四位的？

其实 **umask 本质上是一个「八进制数」**，通常写成 4 位，例如：

```
0022
```

这四位不是随便来的，它代表的是：

| 位数   | 含义                               |
| ------ | ---------------------------------- |
| 第一位 | 特殊权限（setuid、setgid、sticky） |
| 第二位 | 文件拥有者（user）权限掩码         |
| 第三位 | 同组用户（group）权限掩码          |
| 第四位 | 其他用户（others）权限掩码         |

一般我们只关心后三位（`022`），因为第一位通常是 0（不使用特殊位）。
 所以其实你看到的 `0022` 就相当于三组权限：

```
user: 0
group: 2
other: 2
```

------

## 二、为什么要“取反”？

这个是 **umask 的工作原理**：

### 💡 先看“掩码（mask）”这个名字

mask 的意思就是“遮罩”或“屏蔽”。
 umask 表示“哪些权限要被屏蔽掉”。

比如：

```
umask = 0022
```

表示要屏蔽掉：

- group 用户的写权限（2）
- other 用户的写权限（2）

### 那为什么要取反呢？

因为默认情况下，程序创建文件时，会用一个「默认最大权限」：

- 对文件：0666（即 `rw-rw-rw-`）
- 对目录：0777（即 `rwxrwxrwx`）

然后再与 `~umask` 按位与，来“去掉”不要的权限。
 举个例子：

```
默认权限 = 0666
umask = 0022
~umask = 0755 （实际相当于只保留了rw-r--r--）
最终权限 = 0666 & 0755 = 0644
```

也就是：

```
rw-rw-rw-
& rwxr-xr-x
= rw-r--r--
```

最终新建文件权限是 `rw-r--r--`。
 **所以 umask 之所以要取反，是因为它代表要屏蔽的权限位，而不是要保留的权限位。**

------

## 三、为什么不直接定义成「要保留的」？

其实可以，但这样反而更麻烦：

操作系统为了兼容 Unix 的早期设计和逻辑一致性，统一规定 **umask 表示屏蔽位（要去掉的）**。
 这符合「掩码」的含义：mask → 用来遮盖的。

举个比喻你就懂了：

- 如果你戴个“防晒面罩”，你想的是「哪些地方不要晒到」；
- 而不是「哪些地方要晒到」。
   这就是 umask 的“反逻辑设计”原因。

------

## 四、每三位二进制的含义

每三位代表一类用户的权限，分别是：

| 权限位    | 二进制 | 八进制 | 含义    |
| --------- | ------ | ------ | ------- |
| r（读）   | 100    | 4      | read    |
| w（写）   | 010    | 2      | write   |
| x（执行） | 001    | 1      | execute |

例如：

```
chmod 755 file
```

就是：

```
user: rwx (4+2+1=7)
group: r-x (4+0+1=5)
other: r-x (4+0+1=5)
```

------

## 五、“同目录不同用户”是怎么回事？

这和**Linux 文件权限模型**有关：

每个文件/目录有三个「身份」：

| 身份             | 说明                               |
| ---------------- | ---------------------------------- |
| owner（拥有者）  | 一般是创建该文件的用户             |
| group（用户组）  | 属于哪个用户组（比如 programmers） |
| others（其他人） | 既不是owner也不在group里的其他用户 |

举个例子：

```
-rw-r--r--
```

含义是：

- 文件拥有者：可读可写
- 同组用户：可读
- 其他用户：可读

所以当你说“同目录下不同用户”、“不同目录下不同用户”，
 其实就是这些不同用户对文件的读写执行权限取决于这三组权限位。

## ✅ 总结

| 问题                         | 答案                                                         |
| ---------------------------- | ------------------------------------------------------------ |
| 为什么 umask 是 4 位？       | 前一位是特殊位，后三位是用户、组、其他三类用户的掩码。       |
| 为什么要取反？               | 因为 umask 表示「要屏蔽的权限」，最终权限 = 默认权限 & ~umask。 |
| 三位二进制代表啥？           | 读（4）、写（2）、执行（1），每三位代表一个用户类别。        |
| 同目录不同用户是怎么区分的？ | 通过 owner / group / others 三类权限来决定。                 |
