```c++
// auto: 懒得写类型，让编译器自己推导
// check: 给这个小秘书起个名字叫 check
// [&]: 嘿，秘书，外面这些 nums, threshold 你随便用（引用）
// (int m): 我每次只给你一个数字 m，你帮我算算
// -> bool: 算完告诉我行(true)还是不行(false)
auto check = [&](int m) -> bool {
    int sum = 0;
    for (int x : nums) { // 直接用了外面的 nums！
        sum += (x + m - 1) / m;
    }
    return sum <= threshold; // 直接用了外面的 threshold！
};
```

[]是空的，看不到外面的nums和threshold，眼瞎，想要用的话必须在括号内传参

[=]是值传递

[&]是引用传递

**要用的话就是，check(m)**
